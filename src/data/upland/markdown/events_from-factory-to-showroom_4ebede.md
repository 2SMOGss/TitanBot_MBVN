# From Factory to Showroom

August 13, 2026

Property decor is a** central gameplay loop **in Upland, bringing more ownership, connectivity, and uniqueness to the world. **Our goal **is to make that experience** accessible** to more property owners while continuing to **expand** the ways players can customize and bring their properties to life.

**We started** by moving foundational decor into the Upland Store, giving more players an easy way to begin decorating. Since then, **we’ve continued** adding new items each week and will keep building out the catalog over time to give players more options. This week, **we also****added** grass to the Store, making **another foundational piece** of property customization **easier **to access.

Now, we’re **working on the next part** of that experience: making **UGC production easier** to manage.

We’re previewing **automatic factory-to-showroom placement**, an upcoming workflow that will let creators choose a destination showroom when they begin manufacturing. As each item is completed, it **will be placed **on the selected showroom property **automatically**. We expect this feature to arrive **before Harvest Season**.

That means **fewer repetitive steps**, less time moving finished products by hand, and **more time **for creators to **design**, **stock **their showrooms, and** build **their businesses.

### From Factory to Showroom, Automatically

Today, creators need to manually place completed products at their showrooms after manufacturing them. With the **new workflow**, that destination will be set when the item is added to the factory queue.

After choosing an item to manufacture, creators will select **where the finished products should go**. They’ll see a list of their owned properties that have showrooms and choose the appropriate destination.

From there, the workflow depends on whether that showroom already has an inventory lot:

- **If an inventory lot already exists:** select the showroom and start the production queue.
- **If an inventory lot still needs to be created:** choose **Add Lot** to open the Property Editor, draw the inventory lot, then return to select the showroom as the destination. Once the destination is set and production begins, **completed items will be placed on that showroom property automatically**.

That means the placement setup happens **once at the start of the production** run, rather than requiring creators to move each finished item manually afterward.

### Less Busywork, More Building

Property decor is becoming a more central part of the Upland experience, and UGC is a key part of that loop.

Automatic factory-to-showroom placement is currently in development and is planned to arrive **before harvest season**.

By removing a repetitive inventory step, creators can spend less time managing finished products and more time designing, stocking showrooms, and building their businesses.

As property decor grows, we want the systems behind it to make creating, selling, and decorating easier for everyone.
