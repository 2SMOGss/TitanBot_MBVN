# UGC Submission Update: Faster Approvals Are on the Way

July 24, 2026

*​**Editor’s Note:** This post has been updated to clarify that the historical 8–12 week approval timeline reflected normal operating conditions. The current backlog extends beyond that standard, and our goal with the new system is not only to catch up, but to ultimately reduce approvals to under one week.*​

Player-created content is a huge part of Upland’s future, and we’re excited to share an important update on UGC submissions.

Our developers have finished building a brand-new** automated approval system **designed specifically for **Upland’s unique UGC pipeline**. This is a custom solution built entirely from scratch and has now **entered its testing phase**.

We’ve already processed and released our** first batch of Map Assets** using this new system and are continuing to fine-tune it as testing progresses. As our confidence in the system grows, we’ll begin moving through submissions at a **much faster pace**.

You should expect to see **additional batches **of approved Map Assets rolling out over the coming weeks. Because the system is **still being tested**, you may occasionally notice issues or inconsistencies. If you do, please let us know so we can investigate and** improve the system**.

If testing continues to go well, we expect to be fully caught up on the current submission backlog **by Harvest Season**. Once we’re caught up, our focus will shift to **further refining and optimizing** the approval process.

Under normal operating conditions, UGC approvals have** historically taken approximately 8–12 weeks**. The current backlog extends beyond that standard, but as this new system ramps up, our goal is not simply to return to the old timeline. We are working toward **reducing submission-to-approval time to under one week**.

**There’s still work ahead**, but we’re excited that this new system is already live, processing submissions, and moving us toward a much faster future for UGC creators.
